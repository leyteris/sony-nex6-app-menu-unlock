# NEX-6 Application 菜单恢复：强制安全门控

## 1. 绝对禁止

- 禁止保证“绝对不变砖”；只承诺按门控降低风险、异常即停、可优先回滚。
- 禁止写 `0x01640001`、`0x00e40002`、区域字符串、型号字段或固件。
- 禁止使用另一台相机的 Backup、其他区域预设或重建 Backup 作为唯一恢复依据。
- 禁止在 updater payload 半启动状态下继续写入。
- 禁止在 patch/sync 异常后直接重试写入。
- 禁止非交互绕过最终确认。
- 禁止相机 `设置 → 初始化 / 恢复出厂`。
- 禁止把官方 1.03 回刷当作设置回滚替代品。

## 2. 写前门控

必须全部满足：

- [ ] 相机菜单或 PMCA 机读确认 NEX-6 / 1.03。
- [ ] 生成有效 `preflight-*.json`，或保存管理员 PMCA GUI 的可信只读输出。
- [ ] 电池满电或至少 80%，电脑接电。
- [ ] USB 直连、无 Hub、无休眠。
- [ ] 插入可识别 SD/MS 卡；仅在后续官方固件恢复时按索尼说明取卡。
- [ ] 相机处于干净 `054C:056C` Mass Storage 起点。
- [ ] `056C`, `0336`, `03E2` 所需 libusb-win32 驱动记录存在。
- [ ] 两次真实整份 Backup 只读均通过 `BackupFile` 校验和。
- [ ] 两次 Backup 的区域、型号、目标值、USB 安装标志一致。
- [ ] 两次 Backup 的所有持久属性、attr、resetData 一致。
- [ ] 原始备份已复制到第二物理位置并复核 SHA256。
- [ ] 用户已明确确认 `0x010709ed 00→01` 并显示备份路径和哈希。

## 3. 允许的动态字段

NEX-6 updater 会话中以下属性可能随时间/计数变化。允许其 data 变化，但不允许 attr/resetData 变化，也不允许其他持久属性变化：

```text
0x0003012C
0x000D0027
0x00150002
0x00580032
0x00580034
0x00580036
0x00580039
0x0058003A
0x0058003C
0x0058003E
0x0058003F
0x00590013
0x00930003
0x00A10003
0x01250005
0x013B0001
```

实现中对应 `VOLATILE_PROP_IDS`。两次原始 SHA256 不同不能直接判定失败；必须做属性级 diff。任何非白名单属性变化都停止。

## 4. 写入中门控

按顺序执行，任一步失败即停止：

1. 两次新鲜 `read_snapshot()`。
2. 保存 `PRECHANGE` 与 `PRECHANGE-VERIFY`，使用 `xb` 防止覆盖。
3. 属性级 pre-read 兼容性检查。
4. 目标值必须为 `00`。
5. 第三次 `BackupPatchDataInterface` 快照必须与前两次持久属性一致。
6. 显示并核对精确确认串。
7. 使用上游两阶段 `apply()`：临时清 attr → 写目标字节 → 恢复 attr → 更新 checksum。
8. `syncBackup()`。
9. 重新读取内存和持久化 Backup。
10. 全属性审计：持久属性仅目标项变化，attr/resetData 不变。
11. 保存 `POSTCHANGE`。
12. 输出 `before`, `writeBackup OK`, `syncBackup OK`, `after`。

## 5. 写后门控

- [ ] 正常退出 updater，必要时完整关机、拔 USB、等待、重新开机。
- [ ] 主菜单出现「应用程序」。
- [ ] 「应用程序列表」可打开。
- [ ] 拍照、回放、Wi-Fi、USB 等基础功能正常。
- [ ] 新进程 `updater-read` 确认 `0x010709ed = 01`。
- [ ] 保存并异地复制最终验证备份。
- [ ] 保留全部日志、清单和哈希。

## 6. 停止条件

| 情况 | 动作 |
|---|---|
| 机型/固件/区域/USB ID 不符 | 停止 |
| 备份 checksum 失败 | 停止 |
| 非白名单属性变化 | 停止 |
| 目标长度不是 1 或 attr 不是 `0x01` | 停止 |
| 写入输出不完整 | 标记未知状态，先只读确认 |
| `Senser product info error 128` | 仅忽略此特定错误 |
| 整份 service-mode Backup 读取超时 | 切换 updater shell |
| 相机电量低或无响应 | 停止、充电、取电池复位 |
| 相机屏幕停在 updater | 先发送 `complete` 或电源循环 |
| 用户未在确认窗口按 OK | 停止并从干净 `056C` 重试一次 |

## 7. 回滚

首选单属性回滚：

```powershell
.\.venv\Scripts\python.exe .\service.py updater-write 0x010709ed 00
```

预期 `before: 01`、`after: 00`。回滚后完整断电重启并重新只读验证。

仅在单属性回滚不可行、且本机原始 Backup 双副本哈希复核完成时，才考虑通过 `setBackupData()` 恢复整份 Backup 设置数据。绝不使用其他相机或区域预设。

## 8. 驱动恢复

操作结束时 `054C:056C` 可能仍为 libusb-win32，导致普通 USB 连接显示「请检查所连接设备」。

以管理员打开设备管理器：

1. 只定位 NEX-6 / Sony USB Device 且 USB ID 为 `054C:056C` 的 libusb-win32 实例。
2. 卸载该设备；不要勾选会删除其他设备驱动的选项。
3. 扫描硬件改动或拔插 USB。
4. 等 Windows 恢复默认大容量存储驱动。
5. 不触碰其他 libusb-win32 设备。
